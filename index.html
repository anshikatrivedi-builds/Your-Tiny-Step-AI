Your gentle plan

    Want to use a real open-weight AI model?

    This app can optionally send your list to Ollama running on your own computer. The model stays on your machine; nothing is sent to a hosted AI provider.

    1. Install Ollama from ollama.com.
    2. In a terminal, run ollama run qwen2.5:3b and wait for the model to download.
    3. To let this webpage call Ollama, start Ollama with browser origins allowed. For a local test, set OLLAMA_ORIGINS=* in your environment before launching Ollama, then restart it. Use this only for local development.
    4. Enable the toggle below and choose Use local AI. If Ollama is unavailable, the app still works in Smart Mode.
